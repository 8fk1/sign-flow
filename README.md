# SignFlow

**PDF書類への押印・日付記入ワークフローをスマートに自動化するデスクトップアプリ**

SignFlow は Electron 製のクロスプラットフォーム対応デスクトップアプリです。  
スキャン済み書類や電子書類への押印・日付入力を、手間なく・正確に・一括で処理できます。

## 主な機能

### PDF処理

| 機能 | 説明 |
|---|---|
| 複数PDF一括読み込み | ドラッグ＆ドロップ またはファイルダイアログで複数ファイルを同時に追加 |
| 出力ファイル名変更 | 各PDFの出力時のファイル名をアプリ上で変更可能 |
| 押印・日付の合成出力 | 元のPDFに印影・日付テキストを合成した新しいPDFを指定フォルダへ出力 |

### 押印モード

#### 一括押印モード
登録済みの書類種別テンプレート（押印座標・使用印影を事前定義）を選び、読み込んだ全PDFへ同じ位置に一括押印します。毎月同じフォーマットの書類を大量処理する場合に最適です。

#### 個別押印（書類種別）モード
ファイルごとに異なる書類種別テンプレートを割り当てて押印します。同じ処理バッチ内で複数種類の書類を扱う場合に使用します。

#### 個別押印（ビジュアル）モード
実際のPDFプレビューを見ながら、印影や日付を自由な位置へドラッグ&ドロップで配置します。テンプレートの事前定義が不要で、書類のレイアウトを確認しながら直感的に操作できます。

### ビジュアルモード詳細機能

- **プレビューのズーム** — 50%〜300%の範囲でキーボードまたはマウスホイールで拡大縮小
- **プレビューのパン（スクロール）** — ズーム時はドラッグで表示領域を移動可能
- **スタンプ配置** — 登録済みの印影画像をドラッグで自由配置、リサイズハンドルでサイズ調整
- **日付テキスト配置** — 任意テキスト・年・月・日を個別追加。フォントサイズ変更対応
- **年月日一括追加** — 年・月・日を一行に並べた日付行を追加。数字間の間隔をドラッグで調整
- **スマート配置** — ズーム中は現在表示されている範囲の中心付近に要素を追加
- **ダブルクリック編集** — 配置済みのテキスト・数字をダブルクリックで直接編集

### 設定・マスタ管理

- **印影画像管理** — PNG・JPG・GIF形式の印影画像を登録・リネーム・削除・差し替え
- **書類種別テンプレート管理** — 書類ごとに押印座標と使用印影のプリセットを登録・編集・削除
- **座標の自動測定** — テスト用PDFをプレビュー表示し、十字照準をドラッグして座標を自動取得してフォームへ反映

## 使い方

### 1. PDFを読み込む

アプリ上部の「押印処理」タブにある**ドロップゾーン**へPDFをドラッグ＆ドロップするか、エリアをクリックしてファイルダイアログから選択します。

- 複数ファイルをまとめてドロップ可能
- 読み込んだファイルはリストに表示され、ファイル名の変更・削除が可能
- 「一括クリア」ボタンで全ファイルを一度に削除

### 2. 押印モードを選ぶ

PDFを読み込むと**処理モード**ラジオボタンが有効になります。

#### 一括押印

1. ドロップダウンから書類種別を選択
2. 「PDF出力」ボタンをクリック
3. 保存先フォルダを選択すると処理を開始

読み込んだ全PDFへ、選択した書類種別テンプレートに定義された座標・印影で一括押印されます。

#### 個別押印（書類種別）

1. ファイルリストの各PDFに対してドロップダウンから書類種別を個別に選択
2. 「PDF出力」ボタンをクリック

#### 個別押印（ビジュアル）

→ [3. ビジュアルモードの詳細操作](#3-ビジュアルモードの詳細操作) を参照

### 3. ビジュアルモードの詳細操作

#### プレビューの操作

| 操作 | 方法 |
|---|---|
| **ズームイン** | `Ctrl + ↑`（Mac: `Cmd + ↑`）または `Ctrl + ホイール上`（Mac: `Cmd + ホイール上`） |
| **ズームアウト** | `Ctrl + ↓`（Mac: `Cmd + ↓`）または `Ctrl + ホイール下`（Mac: `Cmd + ホイール下`） |
| **パン（画面移動）** | ズーム時にPDFプレビュー上をドラッグ |
| **ページ移動** | 「← 前へ」「次へ →」ボタン |

#### スタンプ（印影）を追加する

1. 右パネルの「配置する印影を選択」ドロップダウンから印影を選ぶ
2. 「＋ 追加」ボタンをクリック → プレビュー上に印影が配置される
3. 印影をドラッグして位置を調整
4. 右下のリサイズハンドル（↔）をドラッグしてサイズを変更
5. 印影右上の「×」バッジをクリックで削除

#### 日付テキストを追加する

右パネルの「日付テキスト」セクションで各ボタンをクリックすると、プレビューへ追加されます。

| ボタン | 追加されるもの |
|---|---|
| **＋年** | 年の数値テキスト（例: `2024`） |
| **＋月** | 月の数値テキスト（例: `1`） |
| **＋日** | 日の数値テキスト（例: `15`） |
| **＋カスタム** | 任意入力テキスト（「令和」「年」「月」「日」など） |
| **年月日を一行で追加** | `2024 — 1 — 15` のように一行に年・月・日を並べた要素 |

追加したテキストはドラッグで移動できます。  
**ダブルクリック**すると値やフォントサイズを編集するポップアップが開きます。  
年月日の一行表示では、数字間の「⟺」ハンドルをドラッグして間隔を調整できます。

### 4. PDF出力

ビジュアルモードでの操作が完了したら、右パネルの「**PDFに出力**」ボタン（またはページ下部の「PDF出力」ボタン）をクリックします。  
保存先フォルダの選択ダイアログが開き、指定フォルダ内に `Stamp_YYYYMMDD_HHMMSS/` サブフォルダが自動作成されて出力されます。

## 設定・マスタ管理

「**設定・マスタ管理**」タブから管理画面へアクセスします。

### 印影画像の管理

- **追加**: 「印影を追加」ボタンからPNG・JPG・GIFを登録
- **リネーム**: 印影名をクリックして直接編集
- **差し替え**: 「差し替え」ボタンで別の画像ファイルに置き換え
- **削除**: ゴミ箱アイコンで削除（使用中の書類種別からも参照が外れます）

> 印影画像はOSのユーザーデータフォルダ内（`userData/stamp/`）に保存されます。

### 書類種別テンプレートの管理

各書類種別テンプレートは以下の情報を持ちます：

| 項目 | 内容 |
|---|---|
| 種別名 | 書類を識別する名前（例: `請求書`, `発注書`） |
| 押印ルール | 印影ファイル・X座標（pt）・Y座標（pt）の組み合わせ（複数登録可） |

#### 座標の自動測定

1. 書類種別の編集フォームでテスト用PDFをドロップ
2. PDFがプレビュー表示される
3. 十字照準（「📍 位置測定」ボタンで有効化）をドラッグして押印したい位置に合わせる
4. 「適用」ボタンで座標が自動入力される

## データ保存について

アプリの設定データは**ブラウザの localStorage** に保存されます。アプリを再インストールしてもデータは保持されます。

| データ種別 | 保存先 |
|---|---|
| 印影画像一覧・メタデータ | localStorage (`stamp_images`, `stamp_meta`) |
| 書類種別テンプレート | localStorage (`stamp_doc_types`) |
| 印影画像ファイル本体 | `{userData}/stamp/`（OS のユーザーデータフォルダ内） |

> **userData フォルダのパス**  
> - Windows: `C:\Users\<ユーザー名>\AppData\Roaming\sign-flow\`  
> - macOS: `~/Library/Application Support/sign-flow/`

## ビルド・パッケージ化

### パターンA: フォルダ形式（ポータブル版）

インストール不要で即実行できる実行ファイル一式を出力します。

```bash
npm run build
# または
yarn build
```

| 項目 | 内容 |
|---|---|
| 出力先 | プロジェクトルート → `sign-flow-win32-x64/` または `sign-flow-darwin-x64/` |
| 実行ファイル | `sign-flow.exe`（Windows）/ `sign-flow`（macOS） |
| 内部ツール | `electron-packager` |

### パターンB: インストーラー形式

ユーザーがインストールして使用するセットアップファイルを生成します。

```bash
npm run app:dist
# または
yarn app:dist
```

| 項目 | 内容 |
|---|---|
| 出力先 | `dist/` フォルダ |
| Windows | `sign-flow Setup 1.0.0.exe`（NSIS形式。インストール先ディレクトリ変更可） |
| macOS | `sign-flow-1.0.0.dmg` |
| 内部ツール | `electron-builder` |

### macOS 向けビルドの注意

macOS で DMG をビルドする場合、コード署名（`Developer ID`）がないと配布時に Gatekeeper に警告されます。  
開発・テスト目的であれば未署名のままで問題ありません。

### フォント埋め込みについて

日付テキストをPDFに書き込む際、以下の優先順位でフォントを埋め込みます：

**macOS:**
1. ヒラギノ角ゴシック W3/W4/W6
2. ヒラギノ丸ゴ ProN W4
3. Arial Unicode（`/Library/Fonts/Arial Unicode.ttf`）
4. Helvetica（フォールバック）

**Windows:**
1. 游明朝 (yumin.ttf)
2. 游ゴシック (YuGothR.ttc)
3. メイリオ (meiryo.ttc)
4. MS ゴシック (msgothic.ttc)
5. Helvetica（フォールバック）

> 現在のpdf-lib/fontkitはmacOSのTTCフォーマットのサブセット化に非対応のため、macOSではArialUnicodeにフォールバックします。

# SignFlow

SignFlow は、PDF書類への押印と署名ワークフローをスマートに行うための Electron 製デスクトップアプリケーションです。

---

## 主な機能

- **PDFファイルの読み込み**: ドラッグ＆ドロップまたはファイル選択による複数PDFの一括読み込み。
- **柔軟な押印モード**:
  - **一括押印**: 登録済みの書類種別（座標定義済み）を選択し、複数ファイルへ一括して同じ位置に押印。
  - **個別押印（書類種別）**: ファイルごとに異なる書類種別を設定して押印。
  - **個別押印（ビジュアル）**: 実際のPDFプレビューを見ながら、ドラッグ＆ドロップで印影を直感的に配置して押印。
- **印影画像管理**: 使用する印影画像（PNG, JPG, GIF等）の登録・削除。
- **書類種別・座標管理**:
  - 書類ごとに押印する座標（X, Y）と使用する印影のプリセットを登録。
  - テスト用PDFをプレビューしながらドラッグで照準を合わせ、座標を自動測定して登録フォームへ適用する機能。

## 開発環境の準備

本システムを動作・ビルドさせるには、**Node.js** がインストールされている必要があります。

### 1. 依存関係のインストール

プロジェクトのルートディレクトリで以下のコマンドを実行し、必要なパッケージをインストールします。

```bash
# npm を使用する場合
npm install

# yarn を使用する場合
yarn install
```

---

## 起動方法

開発モードでアプリケーションを起動するには、以下のコマンドを実行します。

```bash
# npm を使用する場合
npm start

# yarn を使用する場合
yarn start
```

## パッケージ化・exe化の手順

Windows向けの実行ファイル（`.exe`）を作成する方法は、用途に合わせて2種類用意されています。

### パターンA：パッケージ化（フォルダ形式での出力）

インストーラーを介さず、実行ファイル（`sign-flow.exe`）を含む実行可能フォルダを出力します。動作確認やポータブル版として配布したい場合に便利です。

```bash
# npm を使用する場合
npm run build

# yarn を使用する場合
yarn build
```

- **出力先**: プロジェクトルートに `stamp-win32-x64/`（または `sign-flow-win32-x64/`）のようなフォルダが生成され、その中に `sign-flow.exe` が作成されます。
- **仕組み**: 内部で `electron-packager` を呼び出し、`./static/img/32x32.ico` をアイコンとして適用した実行パッケージを作成します。

---

### パターンB：インストーラー（.exe）の作成

ユーザーがインストールして使用するためのインストーラー形式（`.exe`）のファイルを生成します。

```bash
# npm を使用する場合
npm run app:dist

# yarn を使用する場合
yarn app:dist
```

- **出力先**: プロジェクトルートに `dist/` フォルダが作成され、その中に `sign-flow Setup 1.0.0.exe` などのインストーラーが生成されます。
- **仕組み**: `electron-builder` を用いて、`package.json` に定義されたビルド構成に従い、インストール先ディレクトリの変更などを許可するインストーラーを生成します。

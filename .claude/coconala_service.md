## サービス内容（約880字）

```
SignFlowは、PDF書類への押印・日付入力作業を自動化するWindows/macOS対応デスクトップアプリです。インストーラー形式でお届けするため、購入後すぐにお使いいただけます。

■ 3つの押印モードで様々な業務に対応

①一括押印モード
テンプレートに登録した書類種別ごとに、複数のPDFへ同じ座標・同じ印影で一括押印。毎月同じ書類を大量処理する方に特に最適です。

②個別押印（書類種別）モード
同じバッチ内で複数種類の書類を扱う際、PDFごとに異なる書類種別テンプレートを割り当てて一括処理できます。

③ビジュアルモード
実際のPDFを画面で確認しながら、印影・日付テキストをドラッグ＆ドロップで自由に配置。テンプレート登録不要で直感的に操作できます。

■ 主な機能

・複数PDF一括読み込み（ドラッグ＆ドロップ対応）
・印影画像の登録・管理（PNG/JPG/GIF対応）
・日付テキストの自由配置（年・月・日の個別追加、または一行まとめて追加）
・スタンプのサイズ・位置をハンドルでリサイズ
・書類種別テンプレートの管理（座標・印影のプリセット登録）
・座標自動測定機能（テスト用PDFで押印位置を視覚的に確認）
・ダークモード / ライトモード対応

■ 動作環境

・Windows 10/11（64bit）
・macOS 10.15（Catalina）以上

■ 提供内容

・Windows用インストーラー（.exe）
・macOS用インストーラー（.dmg）
・操作マニュアル（PDF）
・macOS初回起動時のGatekeeper警告回避手順

■ 完全ローカル動作・セキュリティ安心

すべての処理はお使いのPC上で完結します。書類データや印影画像が外部サーバーへ送信されることは一切ありません。機密性の高い書類にも安心してご利用いただけます。
```

## よくある質問（10件）

### Q1: 対応OSを教えてください
```
Windows 10/11（64bit）およびmacOS 10.15（Catalina）以上に対応しています。
32bit版Windowsや、それ以前のmacOSには対応していません。
なお、パッケージ版（インストーラー）のため、Node.jsなどの別途インストールは不要です。
```

### Q2: 印影画像はどのように用意すればよいですか？
```
お客様ご自身でご用意いただく必要があります。
スキャナーで実際の印鑑をスキャンして画像化したものや、グラフィックソフトで作成した画像が使えます。
対応形式はPNG/JPG/GIF。背景が透明なPNG（透過PNG）を使うとPDF合成時に自然な仕上がりになります。
既製の印鑑画像素材サービスを使う場合は、そのサービスの利用規約をご確認ください。
```

### Q3: インターネット接続は必要ですか？
```
不要です。すべての処理はPC上でローカルに完結します。
インターネットへのアクセスはありませんので、機密書類を扱う環境でも安心してご利用いただけます。
（初回ダウンロード時のみインターネット接続が必要です）
```

### Q4: 複数のPCにインストールできますか？
```
ご購入者ご本人がお使いになる範囲であれば、複数台PCへのインストールは問題ありません。
他者への譲渡・再配布はご遠慮ください。
法人での複数名利用を検討されている場合は、購入前にお問い合わせください。
```

### Q5: アップデートはありますか？
```
購入後のバグ修正アップデートは3ヶ月以内であれば無償で対応します。
機能追加・仕様変更を伴うアップデートは別途ご相談となります。
OSのアップデートにより動作に問題が生じた場合も、可能な範囲でご対応します。
```

### Q6: 複数ページのPDFに対応していますか？
```
対応しています。複数ページのPDFを読み込んだ場合、ビジュアルモードではページを切り替えながら各ページに押印位置を設定できます。
一括押印モードでは、テンプレートに登録した固定座標への押印となります。
```

### Q7: データのバックアップはできますか？
```
設定データ（印影画像・書類種別テンプレート）はPC内の特定フォルダに保存されています。
Windowsは「C:\Users\ユーザー名\AppData\Roaming\sign-flow\」、
macOSは「~/Library/Application Support/sign-flow/」です。
このフォルダをコピーすることでバックアップ・別PCへの移行が可能です。
```

### Q8: パスワードで保護されたPDFは使えますか？
```
現時点では、パスワード保護（閲覧制限・編集制限）が掛かったPDFには対応していません。
あらかじめパスワードを解除した状態のPDFをご用意ください。
```

### Q9: macOSで「開発元が確認できない」エラーが出ます
```
macOS版はAppleの公式署名なしで配布しているため、初回起動時にGatekeeper（セキュリティ機能）の警告が表示されます。
対処法：Finderでアプリを右クリック（または Control+クリック）→「開く」を選択→警告ダイアログで「開く」をクリック
この操作は初回のみ必要です。操作マニュアルにも手順を記載しています。
```

### Q10: 返品・返金は可能ですか？
```
デジタルコンテンツの性質上、ファイルのダウンロード後の返金は原則お断りしています。
ご購入前に動作環境をご確認いただき、ご不明点はお問い合わせください。
万が一、ファイルが破損していて正常に使用できない場合は対応いたします。
```
